# CARA PAKAI MALIKI NOSE DI RASPBERRY PI

Panduan lengkap biar aplikasi akuisisi serial ini bisa jalan di Raspberry Pi, baik lewat
**GPIO UART** (pin RX/TX) maupun lewat **USB** (CH340/CH341 atau FTDI).

> Aplikasi versi sekarang sudah otomatis mendeteksi jumlah sensor dan `FILTERS` sudah
> kosong, jadi **tidak perlu edit kode `app.js` lagi**.

---

## 1. Salin File ke Raspberry Pi

Salin isi folder `docs` ini (minimal `index.html` + folder `static/`) ke Pi. Pilih salah satu:

**Cara A — flashdisk / USB**
Kopikan folder `docs` ke flashdisk dari PC, colok ke Pi, lalu:
```bash
mkdir -p ~/docs
cp -r /media/pi/USB/docs/* ~/docs/
```

**Cara B — dari Windows via `scp` (Pi di WiFi/LAN yang sama)**
Buka PowerShell di PC, sesuaikan IP Pi (contoh `192.168.1.50`) dan username (`pi`):
```powershell
mkdir D:\PiDeploy
scp "D:\Projects\docs\index.html" "D:\Projects\docs\static\*" pi@192.168.1.50:~/docs/
```

**Cara C — git clone GitHub**
```bash
git clone https://github.com/USER/NAMA-REPO.git ~/docs
```

---

## 2. Jalankan Halaman Web di Pi

**Pilihan 1 — buka langsung (paling cepat):**
Buka file di Chromium:
```bash
chromium-browser ~/docs/index.html
```
→ Web Serial jalan di Chromium/Chrome (bukan Firefox).

**Pilihan 2 — lewat server lokal (lebih stabil, disarankan):**
```bash
cd ~/docs
python3 -m http.server 8000
```
lalu buka `http://localhost:8000` di Chromium.

**Pilihan 3 — versi Flask** (opsional, untuk Pi sebagai server sendiri):
Install dependencies-nya sesuai README terpisah, lalu jalankan Flask-nya.

## 3. Koneksi Perangkat

### A. Lewat GPIO UART (tanpa USB)

Sambungkan ke header GPIO:

| Fungsi | Pin | GPIO |
|--------|-----|------|
| TX     | 8   | GPIO 14 |
| RX     | 10  | GPIO 15 |
| GND    | 6   | —      |

⚠️ RX Pi disambung ke TX alat, TX Pi disambung ke RX alat (jangan terbalik).

### B. Lewat USB

Colok saja alat/adaptor CH340/CH341 atau FTDI ke port USB Pi. Port biasanya muncul sebagai
`/dev/ttyUSB0`.

---

## 4. Aktifkan UART + Beri Hak Akses Port

(WAJIB kalau pakai GPIO UART; untuk USB cek langkah `dialout` saja.)

1. Buka terminal di Pi:
```bash
sudo raspi-config
```
2. Pilih **Interface Options** → **Serial Port**.
3. Jawab **NO** untuk *"login shell over serial?"* (biar console pi tidak merebut pin).
4. Jawab **YES** untuk *"serial port hardware enabled?"*.
5. Keluar lalu reboot:
```bash
sudo reboot
```

Setelah reboot, pastikan port-nya ada:
```bash
ls -l /dev/ttyAMA0 /dev/ttyS0 /dev/ttyUSB0 2>/dev/null
ls -l /dev/serial0 2>/dev/null   # symlink ke ttyAMA0 / ttyS0
```

Beri user (pi) hak akses ke port serial:
```bash
sudo usermod -a -G dialout $USER
```
Lalu **logout + login** (atau reboot). Cek dengan `groups` — harus ada `dialout`.

---

## 5. Format Data yang Dikirim Alat

Alat harus mengirim data per baris, dipisah koma / titik-koma / tab / spasi, contoh:

```
12.34, 14.56, 11.22, 13.48
```

**Jumlah angka di baris = jumlah sensor.** Aplikasi otomatis menghitungnya dan menamai
sensor (MQ-8, MQ-135, MQ-7, MQ-3, TGS-822, MQ-136, TGS-813, MQ-4, + Temp/Press/Humid).

**Bonus (opsional):** kalau firmware bisa, kirim sekali saat start baris deklarasi jumlah
sensor agar deteksi langsung akurat tanpa menunggu data:
```
SENSOR_COUNT: 5
```
Format yang dikenali: `SENSOR_COUNT: n`, `SENSORS=n`, `COUNT=n`, `CHANNELS n`, `N_SENSORS=n`.
Baris deklarasi tidak dihitung sebagai data sampel.

Perintah kontrol yang dikirim aplikasi: `EK-Instrumentation\n` saat connect,
`S\n` start sampling, `Q\n` stop, `W\n` cleaning.

## 6. Uji Cepat (Tanpa Browser Dulu)

Pasang kabel dulu, lalu jalankan dari terminal (ganti port sesuai hasil `ls` di atas):

```bash
sudo apt install -y python3-serial
python3 - <<'EOF'
import serial, time
port = "/dev/ttyAMA0"        # ganti /dev/ttyUSB0 kalau pakai USB
ser = serial.Serial(port, 9600, timeout=1)
ser.write(b"EK-Instrumentation\n")
time.sleep(0.5)
ser.write(b"S\n")
time.sleep(10)
data = ser.read(ser.in_waiting or 1)
print("DITERIMA:", data.decode(errors="ignore"))
ser.write(b"Q\n")
ser.close()
EOF
```

- `Permission denied` → masalah grup `dialout` (langkah 4).
- `DITERIMA:` kosong → cek kabel RX/TX, GND, dan baudrate alat harus **9600**.

---

## 7. Test di Browser (Chromium)

1. Buka halaman (`http://localhost:8000` atau buka `index.html`).
2. Klik **CONNECT** → pilih port (`/dev/ttyAMA0` atau `/dev/ttyUSB0`).
3. Klik **SAMPLING** → data masuk ke tabel & grafik, badge `1.00 Hz`.
4. Panel **SESSION > SENSORS** menampilkan jumlah sensor terdeteksi otomatis.

---

## ⚠️ CATATAN PENTING TEGANGAN!

Pin GPIO Raspberry Pi **bekerja pada 3.3V**:

- Alat keluaran **3.3V** (ESP32, STM32, dll.) → boleh langsung colok ke RX/TX Pi.
- Alat keluaran **5V** (Arduino UNO / Nano) → **WAJIB pakai Logic Level Converter**
  di jalur RX-TX. Kalau 5V dicolok langsung ke GPIO Pi, pin-nya bisa rusak!

---

## Troubleshooting Ringkas

| Masalah | Penyebab & Solusi |
|---------|-------------------|
| Port tidak muncul di browser | Browser bukan Chromium; atau user belum masuk grup `dialout` |
| `Permission denied` di Python | Jalankan langkah 4 (grup dialout) lalu login ulang |
| Tidak ada data sama sekali | Cek RX/TX terbalik, GND, baudrate harus 9600 |
| Jumlah sensor salah tampil | Pastikan data tiap baris jumlahnya konsisten, atau kirim `SENSOR_COUNT: n` |
| Halaman tidak muat font/grafik | Pi offline → pakai koneksi internet atau host via server lokal/Flask |
